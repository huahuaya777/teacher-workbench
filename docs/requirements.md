# 产品需求

本文件记录目标与边界，不代表功能已经实现。

**权威入口：** 本文件保存产品需求；[设计参考](../design-reference/README.md)保存已认可视觉来源，[status.md](status.md)保存当前实现与验证状态。交接包中的历史表述不能覆盖本项目后续真实执行结果。

## 已确认需求：用户与设备

- 项目统一名称为“教师AI工作平台搭建”；教师知识库是其中的资料库、题库与检索模块。妻子的个人页面品牌仍为“华华的教学工作台”，其他成员可有自己的名称。
- 第一阶段供 2～5 人使用，支持不同学科。每人可设学科、年级、教材、班级、课表、常用网站入口，不能把九年级写成所有人的固定值。
- 重点场景：人教版九年级数学，任教 19、20 班，使用 WPS 与希沃白板；其首页名称为“华华的教学工作台”。
- 学校主要使用 Windows 11，资料通常在学校电脑 D 盘；少量试卷以 PDF 为主，另有数十份希沃课件，尚未系统整理。日常作业训练是主要场景。现有流程是先在组卷网/学科网选题并下载 Word，再在 WPS 修改。
- 教师直接使用网页/PWA、WPS 与希沃；不要求教师学习 Obsidian 或 Markdown。其他学科尚未实际验收，不宣称同等成熟。
- 已认可的首页 HTML、SVG 与原始原型已于 2026-10-15 从交接包原样复制到 [设计参考目录](../design-reference/README.md)。当前 Django 功能验证页面已采用其浅绿三栏方向；实际视觉仍待用户验收。
- 电脑横版为主要界面；手机需能聊天、拍照上传、查看资料和课表、下载文件。

## 已确认需求：个人首页与课表参考

- 首页沿用已认可的柔和浅色和三栏布局：左侧导航、中间工作区、右侧 AI 助手。导航包含首页看板、出试卷、组题、课件与资料、本学期课表、AI 助手。移动端要有独立 AI 视图，不能只隐藏输入框。
- 中间工作区包含欢迎标题、可编辑教材/年级、作业入口、当天课程、常用操作、本周课表与快捷网站。AI 栏保留多行需求输入、发送按钮和建议提示。快捷入口先以百度、谷歌、组卷网、学科网为参考，每人可修改名称与链接。
- 已核对的数学节次：周一 19 班第 3 节、20 班第 4 节；周二 19 班第 4 节、20 班第 1 节；周三 19 班第 3/5 节、20 班第 4 节；周四 19 班第 2 节、20 班第 1/6 节；周五 19 班第 1 节、20 班第 2 节。周二安排数学限时训练。
- 这些是节次，不是钟点。学期生效日期、各节起止时间、临时调课和节假日规则待核对；原型中的“周二”、23 题/120 分和课程是演示数据，正式版须按用户课表、当前日期和可编辑设置计算。
- 已认可视觉方向的具体文件与颜色记录在 [设计参考说明](../design-reference/README.md)。原型交互仅在浏览器当前页面生效，不能当作已实现的保存、AI 对话、题库或导出。

## 已确认需求：交付与运行

- 第一版是浏览器应用及可安装 PWA。后续考虑 Windows 客户端、本地 D 盘同步与本地程序调用。
- 后端和主资料库放在家中 Ubuntu 服务器。第一版经用户现有 EasyTier 网络访问；用户提供配置称其运行在 PVE LXC 140，外部设备安装客户端后访问家庭网段。用户有域名 `huahuaya.top`，无公网 IPv4，有公网 IPv6。EasyTier 的组网能力不等于网页可信 HTTPS；入口方案见 [网络访问计划](network-access-plan.md)。
- **当前阶段的已确认取舍（2026-10-17）：**暂不使用工作台域名或 Cloudflare 代理，只用 EasyTier 做异地组网。先验证私网路径与最小版浏览器流程；原定第一版的可信 HTTPS/PWA 目标保留到后续阶段，不作为当前 EasyTier 连通测试的完成条件。此取舍不代表普通 HTTP 已满足 PWA 安装条件。
- PWA 所需可信 HTTPS 尚未配置，不能把“可安装”视为已实现。
- 代码与文档保存到 GitHub 私有仓库；业务数据单独备份。用户于 2026-10-29 授权发布，本机已创建私有仓库 `huahuaya777/teacher-workbench`；实际推送状态见 [status.md](status.md)。

## 已确认需求：第一版完整功能目标

1. 管理员创建账号；成员首次登录改密码；支持停用和密码重置。没有独立“体验成员”类型。
2. 每人独立保存教学档案、历史对话、私人资料库、题库及模型配置；可按需续聊并管理/删除记录与档案。新对话按需参考本人教学档案。
3. 另设共享资料区；默认私有，主动共享后他人才能使用。
4. 管理页面负责账号、额度和系统设置，不展示他人私人聊天、文件和密钥。服务器所有者拥有底层管理能力，不承诺管理员在技术上绝对无法读取服务器数据。
5. 上传 Word、PDF、PPTX、图片；旧 Word 格式、扫描 PDF、公式/插图/复杂版式的解析范围待样本验证。希沃专用文件先保存与下载，其解析能力待验证。资料可按学科、年级、教材、章节组织；访问权限也覆盖题目、索引和缓存。
6. 可从本人及有权限的共享题库选原题，生成变式题、新题和混合试卷；保留来源并标明 AI 生成题。教师可设范围、难度、题型、题量与分值，不承诺生成题绝不会与已有题重复。
7. 组卷网、学科网的首期流程是教师自行选题下载后上传；直接网站选题留待以后验证。
8. 每人保存多套试卷模板，可设纸张、栏数、题型、分值及答题空间。
9. 数学公式在 WPS 中可编辑，图形清晰可打印；复杂题目须人工审核。
10. 先预览题目、答案、解析与排版，通过对话换题、降难度或调整版式，再导出学生卷和教师答案版 Word；预览与导出一致性、题分总计与数学正确性需验收。
11. 根据教材生成教案、课堂练习、可编辑 PPTX，并验证希沃使用效果。
12. 生成结果自动存草稿，修改保留历史版本，用户可标记正式成果。
13. AI 仅由用户主动触发；显示任务进度、排队、取消、用量与预估费用，支持额度及有效期。
14. 联网搜索由用户主动开启并显示来源；服务与费用待选择。
15. 每日自动备份到现有 OMV NAS，保留多个版本并验证恢复；目录和具体周期待配置。

## 已确认需求：AI 接入边界

- 成员自行设置厂商、接口地址、API Key 和模型，并能测试连接；管理员可给成员预配体验 API、额度及有效期。OpenAI 兼容接口与其他协议分别适配，填入地址不表示任意厂商全部能力已通用。
- 2026-10-15 用户指定愿意测试千问或 DeepSeek；随后报告千问免费额度已用完，同意通过充值 API 继续。千问 `qwen-flash` 的一次虚构资料接口探测及本机两次作业任务已由用户执行成功，Key 未持久保存，实际账单按用户要求暂缓核对。ChatGPT Plus 仅在官方许可和本项目资格确认后考虑。详见 [运行手册](runbook.md)。
- 各厂商图片、工具调用等能力分别验证，不假设接口兼容即功能兼容。
- 用户希望配偶使用自己现有 Plus 账号的授权。2026-10-15 官方文档核查表明，OpenAI 已提供 [Sign in with ChatGPT](https://developers.openai.com/siwc/quickstart) 的用户授权途径，合资格的 Plus/Pro 用户可在获准应用中使用自己的 ChatGPT 计划处理合资格请求；该流程需要用户亲自登录并授予单独的模型使用权限，不会给应用 ChatGPT 对话或 API Key。当前公开的[计划使用说明](https://developers.openai.com/siwc/token-sharing-open-source)主要针对开放源码及本地托管应用，并说明付费或远程托管应用应另行表达接入意向。**本项目计划为私有仓库、家中服务器供多人使用；是否取得资格，以及一人的 Plus 计划能否用于配偶的独立工作台账号，仍待官方确认，不能承诺或实现未经确认的订阅转发。**
- 不提取 Cookie、复制 Codex 内部凭据、把用户手工发送 token 当作正常配置、自动购买充值或静默切换付费 API。安装 Codex 不等于平台已能调用 AI。
- 上传保存本身不调用 AI；OCR、模型解析或嵌入如会产生费用，必须另有显式触发和说明。费用估算与厂商实际账单分开，无法取得真实余额时不得编造；取消已开始的任务不能保证撤销费用。
- 平台 AI 只能调用已开发的教学工具，不开放任意宿主机或学校电脑命令执行。

## 阶段 1：最小验证版结果与边界

技术方向已于 2026-10-14 确认。最小验证版的核心链路是：上传一份九年级数学资料 → 用户主动触发 AI 生成作业 → 预览修改 → 导出学生卷和教师答案版 Word → 用 WPS 检查公式、答案、图形和排版。最小版从数据模型与访问控制上保留用户归属和默认私有；此阶段不提前制作完整多用户管理界面。**截至 2026-10-17，虚构样例的限定链路已有用户页面/WPS 验收；“预览后提交修改要求”已在预发布页面排队、由用户显式完成任务 2，并验收第 2 版和历史第 1 版。**生成后的虚构草稿已从 Ubuntu 本机配对备份及专用 NAS 副本分别恢复到全新隔离卷；NAS 导入代码和补丁在保有配对旧应用镜像的 Ubuntu 上重建渲染测试镜像也有现场技术结果。真实资料、复杂题、纸张打印、整机恢复和正式发布不随此结果自动通过。现有代码与尚缺能力见 [status.md](status.md)，细节见 [minimal-validation-design.md](minimal-validation-design.md)，后续功能排期见 [backlog.md](backlog.md)。

**当前导航范围（2026-10-16 用户反馈后调整）：** 首页看板、出试卷、我的作业、课件与资料分别进入不同工作页面；“课件与资料”当前只实现资料上传、查看与下载，课件能力待接入。题库“组题”、本学期课表和通用 AI 聊天继续保留在产品目标中，阶段 1 显示“待接入”，不提供指向首页的假入口。右侧 AI 栏暂为界面输入区，输入不会保存；实际作业生成从“出试卷”由教师主动触发。
